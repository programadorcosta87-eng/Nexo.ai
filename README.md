# Nexo - Hub de Inteligências Artificiais

🔗 Acesse o site: https://nexo-ai-3.netlify.app/

Hub que reúne diversas ferramentas de Inteligência Artificial em um só lugar, organizadas por categoria, com acesso direto aos sites oficiais e suporte a PWA.

---

## 📋 Sobre o projeto

O **Nexo** foi criado para facilitar a descoberta e o acesso a diferentes ferramentas de Inteligência Artificial.

Em vez de o usuário precisar memorizar ou pesquisar constantemente diferentes endereços, o projeto organiza as ferramentas em uma interface única, permitindo encontrar rapidamente uma opção de acordo com sua categoria e modelo de utilização.

A proposta é funcionar como um ponto de acesso centralizado para quem utiliza diferentes soluções de Inteligência Artificial no dia a dia.

---

## Funcionalidades

* Catálogo de IAs organizadas por categoria
* Filtros por tipo e preço (grátis/pago)
* Busca rápida
* Links oficiais das ferramentas
* Aplicativo instalável (PWA)
* Interface moderna e responsiva
* Organização das ferramentas para facilitar a descoberta
* Navegação simples e objetiva

---

## Tecnologias

* HTML
* CSS
* JavaScript
* Netlify
* Progressive Web App (PWA)

---

## 🎯 Objetivo do projeto

O Nexo foi desenvolvido pensando principalmente em praticidade.

Com o crescimento da quantidade de ferramentas de Inteligência Artificial disponíveis, encontrar a ferramenta adequada pode se tornar uma tarefa demorada.

O projeto busca resolver esse problema através de uma interface simples, organizada e rápida, reunindo diferentes categorias em um único ambiente.

---

## 📱 Progressive Web App

O Nexo possui suporte a PWA, permitindo que a aplicação seja instalada e utilizada como uma experiência semelhante a um aplicativo.

A interface também foi construída pensando em diferentes dispositivos, incluindo computadores, tablets e smartphones.

## 🚀 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/programadorcosta87-eng/Nexo.ai.git
```

### 2. Entre na pasta

```bash
cd Nexo.ai
```

### 3. Execute localmente

Como o projeto possui uma página HTML independente, você pode abrir o arquivo:

```text
Nexo.ai.html
```

diretamente no navegador.

Também é possível utilizar um servidor local para executar o projeto.
